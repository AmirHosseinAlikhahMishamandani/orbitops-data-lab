# Contributing

OrbitOps is primarily a portfolio project, but it follows the same contribution discipline expected in a shared codebase.

1. Create a focused feature branch from current `main`.
2. Keep commits cohesive and use meaningful Conventional Commit-style subjects.
3. Add or update tests with behavioral changes.
4. Run `make check` before pushing.
5. Use the pull request template and document design tradeoffs and limitations.
6. Do not commit generated datasets, local DuckDB files, secrets, or environment files.
